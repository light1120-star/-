Loop 反馈闭环设计师 — 使用说明

用途
你提出任务想法，技能生成可修改的 Feedback Loop 和完整 Agent 执行指令。
它负责设计目标、证据、验收、修复、重试上限与停止条件。
默认先交付设计；你同时要求执行时，才在可用工具和授权范围内执行。

在 Codex 中安装
1. 解压此 ZIP，找到 loop 文件夹。
2. 将整个 loop 文件夹放入个人技能目录。
   Windows：在文件资源管理器地址栏输入 %USERPROFILE%\.agents\skills
   macOS / Linux：~/.agents/skills
   目录不存在时创建即可。
3. 确认最终结构是 .agents/skills/loop/SKILL.md，避免多套一层 loop 文件夹。
4. Codex 会自动检测技能；如果未出现，重启 Codex 再检查。
   不同版本或受管理环境可让 Codex 核对实际技能发现目录。

也可以让对方的 Codex 帮忙安装
将 ZIP 保存到本地，在 Codex 中说：
“请读取我指定位置的 loop-skill-分享包.zip，检查后安装到本机个人技能目录。
保留 loop 文件夹中的全部文件。如果已存在同名技能，先比较并说明差异，不要直接覆盖。
安装后检查文件完整性，并告诉我如何调用。”
同时提供 ZIP 的实际本地路径，或在支持文件附件的环境中附上文件。

调用示例
$loop 我想用100个关键词研究英国真人接发竞品，最后整理成Excel。
帮我设计可以直接使用的Feedback Loop；不确定的验收标准先给建议。

修改示例
把每个关键词的有效结果数改成至少10个，总尝试次数最多3次，更新整个Loop和执行指令。

执行示例
按这个Loop执行，保存验证证据；未达标项列出停止原因和下一步。

说明
这是一份本地技能文件分享包，不是已经发布的插件。
业务执行所需的搜索、表格、浏览器等能力由对方环境提供，不包含你的账号或连接权限。
本包已检查压缩包完整性及与源文件逐字节一致；尚未在接收者电脑上验证安装。
