# 短剧自动剪辑

默认目标：视频号短剧推广，成片240–300秒，前三秒呈现有证据的爆点，随后保持剧情推进。用户后续明确的时长、平台、画幅与风格要求覆盖默认值。

字幕规则：本用户的成片只保留原素材自带字幕，不新增、重做、翻译、烧录或叠加字幕，也不添加文字层；没有字幕的区间保持无字幕，不擦除或遮盖原字幕。恢复语音转写、字幕识别、OCR和字幕文本提取，用于内部剧情分析和切点判断；这些分析结果不自动写入成片。

## 执行原则

- 必须先读取素材并建立时间索引，再提取爆点，最后生成剪辑时间线和执行剪辑。不能用随机切片或预设时间模板代替理解剧情。
- “读取”包含覆盖素材的对白分析与镜头/关键帧观察。仅转写不能算看完视频，稀疏抽帧不能算理解全部动作。记录分析覆盖范围和未观察区间，对爆点及前后关联片段加密观察并检查音频；不虚构无法确认的台词。
- 不把喊叫、音量峰值、快速转场、关键词单独当成爆点。根据冲突、人物可能失去什么、信息变化、人物反应和前后因果判断。
- 保留人物动机、指代、空间与事件连续性。不得为制造反转虚构台词、调换台词归属或拼出原剧情不存在的事实。
- 一集不足可从连续几集取材。高质量内容不足以撑满240秒时，明确缺口并请求相邻素材，不能重复、慢放或插入无关画面凑时长。
- 用户已要求自动剪辑时，完成分析后继续执行可用的本地步骤，不把爆点清单审批设成必经关卡。用户仅要求分析时交付分析即可。
- 技能不自带语音/视频模型、外部账号或媒体程序。缺少依赖时准确报告并完成不依赖它的步骤，不宣称已经读完或剪完。

## 1. 读取与建索引

先运行 `scripts/drama_edit.py doctor` 检查依赖；运行方式与文件结构见 [references/workflow.md](references/workflow.md)。使用已有可用工具，不必安装所有可选库。读取文件目录时确定集数顺序，不只按文件名字符串排序。

用媒体检测获取时长、分辨率、帧率、音轨和字幕轨。优先读取已有可靠字幕并核对同步；否则使用可用的中文语音识别工具转写，保留句级时间点。画面硬字幕可用OCR核对人名、身份、台词与切点。观看人物动作、场景变化和事件关系，不仅凭文字判断剧情。转写稿和OCR结果仅存入工作目录。

按镜头切换和定时抽帧建立视觉覆盖，在事件密集处补充。保留每集原始时间轴，不把音频分块时间误当成整集时间。记录识别置信度和无法确认的部分；必要时结合原片复核，仍不确定时请求情节说明。

## 2. 爆点清单

每个候选记录：素材文件、起止秒数、关键台词/动作证据、人物关系、事件类型、必要铺垫、结果、是否适合独立开场、置信度和未确认事项。按以下维度各给0–5分，评分用于相对筛选，不是预测播放量：

- 开场理解度：前三秒能否看懂矛盾或产生具体疑问。
- 冲突强度：是否存在明确目标、阻碍和代价。
- 信息增量：新证据、身份揭示、局势改变或反转。
- 连贯性：放入时间线后，人物动机和指代是否成立。
- 后续承接：是否有足够剧情兑现并继续升级。

输出 `analysis.md`，附覆盖范围、剧情梗概和带原片时间点的爆点表。不编造缺失时间点。

## 3. 编排4–5分钟成片

选取最合适的开场，不一定是全剧最晚或最激烈的一刻。前三秒是爆点进入时间，不要求把整场戏压到三秒内。若用后段预告式开场，回到前因时用清楚的过渡，避免重复播放整段高潮。

中段按因果串联冲突升级，删重复说明、无信息停顿和无关支线；保留建立张力所需的反应和短暂停顿。以约20–40秒一次有意义的变化作为检查提示，不作为强制切点或虚构高潮指标。

兑现部分期待，再在有真实后续的关键转折处结束；不能只堆悬念没有任何结果。切点尽量落在句尾、动作完成或自然镜头边界。

生成可复查的 `edit-plan.json`，包含原片区间、顺序和选段理由。使用辅助脚本校验时间范围、重叠重复和总时长。校验通过不代表剧情通过，仍需审阅实际内容。

## 4. 剪辑与声音

使用已有视频处理工具或附带的渲染脚本执行计划。保留原素材，输出到新的任务目录。默认竖屏1080×1920、30fps仅是制作预设，不声称是视频号强制规范。横屏先评估人物与字幕位置，优先完整保留画面；裁切前检查重要人物、证据和原字幕。

附带脚本提供等比留边的基础拼接，保留原声与画面内原有字幕；语音转写和OCR使用可用工具完成。结合识别结果与画面判断剧情，记录实际完成项。当前成片要求不允许补加字幕或文字层。音乐不盖对白，不能未经检查做强降噪或把静音直接视为无用。

原片硬字幕随画面保留，识别仅用于分析，不重新绘制。若原素材使用独立字幕轨，附带基础渲染脚本不会保留该轨，须使用能按选段同步保留原轨的工具；不要烧录为新文字层，也不要静默丢弃原轨。内部OCR和转写文件不作为成片字幕加载。

## 5. 成片检查与交付

检测成片能否解码、时长是否在目标区间、音视频时长是否异常，并检查黑帧、意外静音、冻结画面等可疑区间。黑场和静音可能是剧情，检测后再判断。

观察开头、每个接缝和结尾；结合整条成片的音频与画面检查字幕同步、人物关系、断句、连续重复和竖屏可读性。工具能力不足以完成某项检查时，交付记录中明确写“未验证”，不能写“全部通过”。只修复有证据的问题。

字幕专项检查：对照原片和成片对应画面，确认字幕内容、样式、位置随原画面保留，渲染流程没有新增文字层。发现原片字幕错误时仅记录，不自行重做或覆盖。

交付：成片MP4、`analysis.md`、`edit-plan.json`、`quality-report.md`，不交付新生成的字幕文件。报告注明仅保留原素材字幕，以及依赖/分析覆盖限制和需要人工确认的剧情点。发布标题和封面文案可单独提供为文本，不叠加到成片；播放与停留效果需真实发布数据验证。

发布、账号操作、短剧小程序挂载不包含在本技能的本地剪辑授权中；用户另行要求时按实际入口处理。不要为了剪辑要求用户先提供账号或挂载权限。
